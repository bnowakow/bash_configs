Scope

Values are median final ffmpeg speed= values, in multiples of realtime. h264_qsv and h264_vaapi are hardware encoders; libx264 is software encoding.

Full-log validation

  • All 228 Proxmox ffmpeg logs have an Lsize line, muxing summary, and output file.
  • All 21 NAS-host ffmpeg logs have an Lsize line, muxing summary, and output file.
  • Proxmox runs 193–228 have no ffmpeg logs, although output files exist; these cannot be treated as clean ffmpeg passes.
  • Proxmox runs 121–144 and 157–168 contain repeated Error while decoding stream #0:0: Input/output error messages in all three storage layouts. They produced output but are errored/degraded, not clean passes.
  • The NAS-host ffmpeg logs contain no decoding or conversion failure markers.

There are no asymmetric clean pass/fail results in the 21-test overlap. Proxmox has 48 decoding-I/O-error tests, common to all three Proxmox layouts, suggesting a host/input-side issue rather than a read/write-path issue.

Input bitrates are decimal conversions of ffmpeg-reported container bitrates: 1 MB/s = 1,000 kb/s.
